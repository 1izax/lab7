# Домашнее задание к работе 4
## Условие задачи
Записать программу, которая на ввод времени суток выводит соответствующее пожелание доброго утра, доброго дня, доброго вечера и спокойной ночи.
## 1. Алгоритм и блок-схема
### Алгоритм решения
1. Начало
2. Объявить константу и переменные:
   - число от первого датчика: A
   - число от второго датчика: B
3. Ввести значение переменной:
   - ввод значения A
   - ввод значения B
4. Вычислить логическое условие:
   - condition = (A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0)
5. Вывести результаты расчетов с подстановкой всех значений в текст
6. Конец

## 2. Реализация программы
```
#include <stdio.h>
#include <locale.h>

int road()
{
	setlocale(LC_CTYPE, "RUS");

    int A, B, condition;
    printf("=== СИСТЕМА ВЫБОРА МАРШРУТА ===\n");
    printf("Введите два целых числа (датчик A и датчик B): ");
    scanf("%d %d", &A, &B);

    condition = ((A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0));

    printf("Направление НАЛЕВО (1 - да, 0 - нет): %d\n", condition);
}

int main()
{
	road();
	getchar();
	return 0;
}
```
